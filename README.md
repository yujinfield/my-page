# 🐻 곰메모 (Bear-like Notes)

아이폰 [Bear](https://bear.app) 앱처럼 **깔끔하고 가벼운 마크다운 메모 웹사이트**입니다.
설치나 회원가입 없이 브라우저에서 바로 쓰고, 메모는 내 브라우저에 저장됩니다.

> 이 저장소에는 기존 페이지(`index.html`, 2023 버킷리스트)가 함께 있습니다.
> 메모 앱은 `memo/` 폴더에 만들어 기존 페이지와 분리합니다.

---

## ✨ 주요 기능

### 1차 목표 (MVP)
- **메모 작성/수정/삭제** — 첫 줄이 자동으로 메모 제목이 됩니다.
- **마크다운 지원** — `# 제목`, `**굵게**`, `*기울임*`, `- 목록`, `- [ ] 할 일`, `> 인용`, `` `코드` ``, 링크
- **해시태그로 정리** — 본문에 `#여행`, `#공부/일본어`처럼 쓰면 자동으로 태그가 생깁니다.
  - `/`로 **중첩 태그**(하위 태그)를 만들 수 있습니다.
  - 폴더 대신 태그로 정리하는 것이 Bear의 핵심 방식입니다.
- **3단 레이아웃** — 사이드바(태그) │ 메모 목록 │ 편집기
- **검색** — 제목·본문 전체에서 실시간 검색
- **자동 저장** — 타이핑을 멈추면 자동으로 저장 (`localStorage`)
- **다크 모드** — 시스템 설정을 따르고, 직접 전환도 가능
- **모바일 대응** — 아이폰에서는 한 화면씩(목록 → 편집기) 슬라이드 전환

### 2차 목표
- 메모 **고정(핀)** 및 **휴지통**(복구 가능)
- 할 일 체크박스 클릭으로 완료 표시
- 정렬: 수정일 / 생성일 / 제목
- 글자 수 · 단어 수 · 읽는 시간 표시
- 메모 **내보내기/가져오기** (`.md`, `.json` 백업)
- 테마 선택 (Bear처럼 색상 테마 여러 개)
- PWA — 아이폰 홈 화면에 추가해 앱처럼 사용, 오프라인 동작

## 🛠 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 화면 | HTML + CSS (Flexbox/Grid, CSS 변수) | 빌드 없이 바로 열림 |
| 동작 | 순수 JavaScript (ES Modules) | 프레임워크 학습 부담 없음 |
| 저장 | `localStorage` (추후 IndexedDB 고려) | 서버 없이 브라우저에 저장 |
| 마크다운 | [marked](https://marked.js.org) + [DOMPurify](https://github.com/cure53/DOMPurify) (CDN) | 렌더링 + XSS 방지 |
| 폰트 | Pretendard 또는 Google Fonts | 한글 가독성 |
| 배포 | GitHub Pages | 무료, push 하면 바로 반영 |

## 📁 폴더 구조 (예정)

```
my-page/
├── index.html          # 기존 버킷리스트 페이지
├── README.md
├── CLAUDE.md           # AI 작업 가이드
└── memo/
    ├── index.html      # 메모 앱 진입점
    ├── css/
    │   ├── base.css    # 색상 변수, 폰트, 리셋
    │   ├── layout.css  # 3단 레이아웃, 반응형
    │   └── editor.css  # 편집기/마크다운 스타일
    └── js/
        ├── app.js      # 초기화, 이벤트 연결
        ├── store.js    # 메모 저장/불러오기 (localStorage)
        ├── tags.js     # 해시태그 추출, 태그 트리
        ├── editor.js   # 편집기, 자동 저장
        ├── list.js     # 메모 목록, 검색, 정렬
        └── sidebar.js  # 태그 사이드바
```

## 🚀 실행 방법

빌드 과정이 없습니다. ES Modules 때문에 파일을 더블클릭하는 대신 간단한 로컬 서버로 여세요.

```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/memo/ 접속
```

또는 VS Code의 **Live Server** 확장으로 `memo/index.html`을 열어도 됩니다.

### 배포 (GitHub Pages)
1. GitHub 저장소 → **Settings → Pages**
2. Source: `main` 브랜치, `/ (root)` 선택
3. `https://<아이디>.github.io/my-page/memo/` 에서 확인

## 🗂 데이터 형식

메모는 `localStorage`의 `bear-notes` 키에 JSON 배열로 저장됩니다.

```json
{
  "id": "n_1697270400000",
  "content": "# 일본 여행 준비\n\n- [ ] 여권 확인\n#여행/일본",
  "pinned": false,
  "trashed": false,
  "createdAt": 1697270400000,
  "updatedAt": 1697270400000
}
```

- 제목과 태그는 저장하지 않고 `content`에서 **매번 계산**합니다. (데이터가 하나뿐이라 꼬이지 않음)
- ⚠️ 브라우저 데이터를 지우면 메모도 사라지므로, 중요한 메모는 내보내기로 백업하세요.
