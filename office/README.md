# 🏢 AI 사무실

AI 직원을 채용해서 블로그팀·인스타팀을 꾸리는 도트 그림 사무실 웹사이트입니다.
직원들은 GPT(OpenAI API)로 생각하고 말합니다. 나 혼자 쓰는 사이트라서 서버 없이 동작하고,
API 키와 회사 데이터는 내 브라우저(`localStorage`)에만 저장됩니다.

## 쓰는 법

1. 오른쪽 위 ⚙︎ 설정에 OpenAI API 키를 넣습니다. (https://platform.openai.com/api-keys)
   - ChatGPT 구독과는 별개로, API는 쓴 만큼 요금이 나갑니다.
   - 모델 이름은 설정에서 바꿀 수 있습니다.
2. **채용** 탭에서 공고를 올리면 지원자 3명이 옵니다. 마음에 드는 사람을 채용합니다. (팀마다 4자리)
3. 사무실에서 직원을 누르거나 **메신저** 탭에서 대화합니다.
   - **업무 지시**를 누르면 직원이 일을 시작하고(머리 위에 "Work!"), 끝나면 완료 보고 메시지가 옵니다.
4. (선택) 설정의 **Uplika 연결**에 Uplika 화면 "주소만 추가"로 복사한 주소를 넣고 연결 → 승인하면,
   직원들이 회의와 업무 때 내 계정의 인사이트·게시물·네이버 노출을 직접 조회합니다. 발행은 하지 않습니다.
5. **회의실**에서 안건과 자료(최근 글, 캡션, 통계 등)를 붙여 넣으면 직원들이 돌아가며 토론합니다.
   - "한 번 더 토론"으로 이어 가고, "결론 정리"로 결론과 할 일을 받습니다.

## 실행

```bash
python3 -m http.server 8000   # http://localhost:8000/office/
```

## 로드맵

### 1단계
- [x] 도트 사무실 화면 (블로그팀/인스타팀 자리, 말풍선, 일하는 모습)
- [x] 채용 공고 → 지원자 3명 → 채용 / 퇴사
- [x] 사내 메신저 (대화, 업무 지시 → 완료 보고 알림)
- [x] 회의실 (돌아가며 토론, 대표 한마디, 결론 정리, 지난 회의 보기)
- [x] 설정 (API 키, 모델, 내 블로그·인스타 소개), 다크 모드, 휴대폰 화면

### 2단계
- [ ] 면접: 채용 전에 지원자에게 질문하기
- [x] Uplika 연결: 직원이 내 블로그·인스타 인사이트와 네이버 노출을 직접 조회 (회의·업무, 읽기 전용)
- [ ] 결재: 직원이 쓴 초안을 승인하면 발행
- [ ] 데이터 내보내기/가져오기 (백업)
