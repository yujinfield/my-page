# 거북이 클럽 (Turtle Club)

책을 읽고 몸을 풀며, 조금 덜 서두르는 사람들의 작은 월간 클럽 소개 사이트입니다. 순수 HTML/CSS/JS, 외부 라이브러리 없음.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 홈: 첫 화면 · 브랜드 문장 · 이번 달의 모임 · 우리가 하는 일 · 모임장 |
| `yoga.html` | 온라인 인요가 상세: 이런 날 · 60분 흐름 · 모임장 · 신청 정보 박스 |
| `book.html` | 독서모임 상세: 이달의 책 → 이런 이야기 → 모임장 → 일정/신청 |
