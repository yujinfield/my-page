# 🧠 무한 마인드맵

끝없이 넓어지는 캔버스 위에 **마인드맵(가지)**과 **논리·순서 흐름(화살표)**을 함께 그리는 웹사이트입니다.
설치나 회원가입 없이 브라우저에서 바로 쓰고, 지도는 내 브라우저(`localStorage`)에 저장됩니다.

- 주소: `https://yujinfield.github.io/my-page/mindmap/`
- 로컬 실행: 저장소 폴더에서 `python3 -m http.server 8000` → `http://localhost:8000/mindmap/`

## 연결선 두 종류

| 종류 | 용도 | 모양 | 만드는 법 |
| --- | --- | --- | --- |
| **가지** | 마인드맵 부모 → 자식 | 회색 곡선 | `Tab`(자식), `Enter`(형제) |
| **화살표** | 논리·순서·인과 ("그래서", "왜냐하면") | 빨간 화살표 + 라벨 | 주제의 ● 손잡이를 끌어 다른 주제에 놓기, 또는 `L` 누르고 주제 누르기 |

화살표를 고르고 `Enter`(또는 두 번 누르기)를 누르면 라벨을 달 수 있습니다.

## 결정 주제 (시퀀스·순서도)

주제를 고르고 `D`(◇ 결정 버튼)를 누르면 **마름모 모양 결정 주제**가 됩니다.
나가는 화살표가 없으면 **"예"(오른쪽)·"아니오"(아래)** 갈래가 자동으로 생기고,
결정 주제에서 새로 잇는 화살표에도 "예" → "아니오" 라벨이 차례로 붙습니다. 다시 `D`를 누르면 보통 주제로 돌아갑니다.

## 순서 번호와 따라가기 재생

- `N`(번호 버튼): 화살표를 따라가는 순서대로 주제 왼쪽 위에 **1, 2, 3…** 번호를 붙입니다.
  - 들어오는 화살표가 없는 주제에서 시작해서, 한 갈래를 끝까지 따라간 뒤 다음 갈래로 넘어갑니다.
  - 갈래가 나뉘면 "예"가 먼저, "아니오"가 마지막입니다.
- `P`(▶ 재생 버튼): 같은 순서로 주제를 하나씩 강조하며 화면을 옮깁니다. 발표하거나 논리를 점검할 때 씁니다.
  - `→`·`Space`·`Enter` 다음, `←` 이전, `Esc` 끝내기 (아래 ◀ ▶ ✕ 버튼도 있음)
  - 재생 중에 주제를 누르면 그 단계로 건너뜁니다.

## 정리하기

- `A`(정렬 버튼): 가지(마인드맵)를 겹치지 않게 다시 놓습니다. 주제를 골랐으면 그 나무만, 아니면 모든 나무를 정렬합니다. 가장 위 주제는 그 자리에 둡니다.
- `F`(접기 버튼): 고른 주제의 가지를 접습니다. 접힌 주제 옆의 **+숫자**를 누르거나 다시 `F`를 누르면 펼쳐집니다.

## 조작법

| 동작 | 키보드 / 마우스 | 휴대폰 |
| --- | --- | --- |
| 자식 / 형제 주제 추가 | `Tab` / `Enter` | ＋ 자식 / ＋ 형제 버튼 |
| 글자 고치기 | `Space`, `F2`, 두 번 클릭 | 편집 버튼, 두 번 탭 |
| 편집 마치기 | `Enter` (줄바꿈은 `Shift+Enter`), `Tab`은 마치고 바로 자식 추가 | 빈 곳 탭 |
| 새 주제(따로 떨어진) | 빈 곳 두 번 클릭 | 빈 곳 두 번 탭 |
| 주제 옮기기 | 끌기 (자식도 같이 움직임) | 끌기 |
| 화살표 잇기 | ● 손잡이 끌기, `L` | ● 손잡이 끌기, → 연결 버튼 |
| 결정 주제 ↔ 보통 주제 | `D` | ◇ 결정 버튼 |
| 주제 색 | `C` (차례로 바꾸기) | ● 색 버튼 → 색 고르기 |
| 자동 정렬 | `A` | 정렬 버튼 |
| 가지 접기 / 펼치기 | `F`, **+숫자** 누르기 | 접기 버튼, **+숫자** 탭 |
| 순서 번호 보기 | `N` | 번호 버튼 |
| 따라가기 재생 | `P` | ▶ 재생 버튼 |
| 삭제 | `Delete` / `Backspace` (자식도 함께) | 삭제 버튼 |
| 되돌리기 / 다시 실행 | `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` (맥은 `⌘`) | ↶ / ↷ 버튼 |
| 주제 사이 이동 | 방향키 | 탭 |
| 화면 이동 | 빈 곳 끌기, 휠 | 빈 곳 끌기 |
| 확대 / 축소 | `Ctrl`+휠, `+` / `-` | 두 손가락 벌리기 |
| 전체 보기 / 100% | `0` / `1` | 전체 버튼 |
| 선택 해제, 연결 취소 | `Esc` | 빈 곳 탭 |

## 데이터 형식

`localStorage`의 `mindmap-data` 키에 저장됩니다.

```json
{
  "version": 1,
  "nodes": [{ "id": "n_1730000000000_1", "text": "중심 주제", "x": 0, "y": 0, "shape": "decision", "color": "blue", "collapsed": false }],
  "edges": [{ "id": "e_1730000000000_2", "from": "n_…", "to": "n_…", "type": "flow", "label": "그래서" }],
  "view": { "x": 0, "y": 0, "zoom": 1 },
  "showNumbers": false
}
```

- `type`: `"branch"`(가지) 또는 `"flow"`(화살표)
- `shape`(없어도 됨): `"topic"`(기본, 둥근 사각형) 또는 `"decision"`(마름모)
- `color`(없어도 됨): `null` 또는 `"red"`, `"orange"`, `"yellow"`, `"green"`, `"blue"`, `"purple"`
- `collapsed`(없어도 됨): `true`면 자손을 숨김
- `showNumbers`(없어도 됨): 순서 번호를 보일지
- 실행 취소 기록은 저장하지 않습니다. (새로고침하면 비워짐, 최대 100번)
- 부모-자식 관계는 따로 저장하지 않고 `branch` 연결선으로 알아냅니다.
- ⚠️ 브라우저 데이터를 지우면 지도도 사라집니다. (내보내기는 4단계 예정)

## 🗺 로드맵

- [x] 1단계: 무한 캔버스(끌기 이동·휠/핀치 확대), 주제 추가/편집/삭제/끌기, 가지 연결, 화살표 + 라벨, 자동 저장, 다크 모드, 모바일
- [x] 2단계: 실행 취소/다시 실행, 결정 주제(마름모, 예/아니오 갈래), 주제 색
- [x] 3단계: 자동 정렬, 가지 접기/펼치기, 순서 번호, 화살표 따라가기 재생
- [ ] 4단계: 미니맵, 검색, 그룹(프레임), JSON 내보내기/가져오기, 여러 지도
