# 🐿️ 꼼쥐툰 메이커 (@꼼쥐 인스타툰 제작 도우미)

인스타그램 계정 **@꼼쥐**의 인스타툰·릴스 기획을 돕는 웹사이트입니다.
주제와 실제 경험을 입력하면 [꼼쥐 프로젝트 지침](./guidelines.md)에 맞춰
**컷 구성표 → 컷별 콘티 → 이미지 생성 프롬프트 → 캡션**까지 텍스트로 정리해 줍니다.

> 이 사이트는 이미지를 직접 그리지 않습니다.
> 결과물은 Make 등 이미지 생성 도구에 바로 붙여 넣을 수 있는 **완성형 텍스트 콘티**입니다.

---

## ✨ 주요 기능

### ✅ 지금 쓸 수 있는 기능: 통합 입력폼 → 콘티 요청문
스토리형 V1과 정보형 V2 마스터 프롬프트의 입력 항목을 **하나의 폼**으로 합쳤습니다.

1. **PART 1 기본 정보** — 제목, 독자 질문, 주제, 시작된 경험, 당시 감정·고민, 결과·느낀 점
2. **PART 2 핵심 정보 ①②③** — 핵심 내용(선택한 이유 또는 꿀팁), 실제 사례, 한 줄 핵심
3. **PART 3 마무리** — CTA 방식, 댓글로 보낼 자료, 댓글 키워드, 댓글 유도 문구
4. **결과** — 입력 내용을 보고 **스토리형인지 정보형인지 자동 판단**하고, 판단 이유를 보여줍니다.
   - 판단이 마음에 안 들면 직접 바꿀 수 있습니다.
   - 고른 유형의 마스터 프롬프트 + 입력 내용을 합친 요청문을 만들어 **복사**합니다.
   - claude.ai 꼼쥐 프로젝트에 붙여 넣으면 컷별 콘티와 이미지 프롬프트를 받습니다.

- 입력 진행률 표시, 빈칸이 있어도 제출 가능 (빈칸은 "지어내지 말고 확인 필요"로 표시)
- 입력 내용은 브라우저에 자동 저장되어 새로고침해도 남아 있습니다.

### ✅ 컷 편집기
5. **컷 편집** — 입력 내용으로 기본 컷 구성을 만들고 컷마다 다듬습니다.
   - 컷 추가·삭제·순서 변경, 템플릿 4종(표지형·스토리형·정보형·비교형) 선택
   - 템플릿별 문구 칸, 표정·등장 캐릭터·배경·장면·연출 메모
   - 컷별 **이미지 생성 프롬프트** 자동 조립 + 복사, 전체 한 번에 복사
   - **자동 검토**: 대사 줄 수·15자 초과, 입력폼에 없는 숫자, 가격 등 검증 필요 정보, 브랜드 로고, 앞 컷과 같은 문장, 비교형 좌우 항목 수, 컷 수

### ✅ 댓글 자료 → 노션
- PART 3에서 **댓글로 보낼 자료 종류**를 고릅니다: 자료 없음 / 체크리스트 / 비용 정리 / 제품·장소 목록 / 일정·타임라인 / 기타
- **✨ Claude에게 자료 초안 쓰기** → 초안을 직접 고친 뒤 → **노션에 저장**하면 노션에 비공개 페이지가 만들어지고 링크가 남습니다
  - 입력한 정보만 쓰고, 일반 정보·가격·시기에는 "(검증 필요)"를 붙입니다
  - claude.ai 링크에서만 자동으로 되며, claude.ai에 Notion 커넥터가 연결되어 있어야 합니다
  - 내 컴퓨터에서 열면 **노션 요청문 복사** 버튼으로 요청문을 복사해 Claude에게 부탁합니다
- 자료가 준비되면 콘티 요청에 "노션에 준비 완료"로 전달되어 댓글 키워드 CTA를 쓸 수 있습니다

### ✅ 그림 생성 (GPT)
- 컷 편집 화면의 **🎨 그림 생성 (GPT)** 카드에서 OpenAI API 키·모델·크기·품질을 정합니다
  - 키는 이 브라우저에만 저장되고 GitHub에는 올라가지 않습니다 ("지우기"로 삭제)
  - 기본: `gpt-image-2`, 1024×1280(4:5). 모델이 크기를 거절하면 1024×1536(2:3)이나 다른 모델을 고르거나 직접 입력
- 컷마다 **🎨 이 컷 그림 만들기**, 또는 **전체 컷 그림 만들기**(그림마다 비용, 시작 전 확인, 멈추기 가능)
- 꼼쥐 턴어라운드 + 해당 템플릿 레퍼런스 이미지를 함께 보내 외형을 유지합니다 (끌 수 있음)
- 만든 그림은 화면에만 있으니(새로고침하면 사라짐) **내려받기**로 저장하세요
- **공용 링크(github.io)나 내 컴퓨터(localhost)에서 열었을 때** 됩니다. claude.ai 링크는 외부 인터넷이 막혀 있어 OpenAI에 연결할 수 없습니다

### ✅ Claude 콘티 자동 작성
6. **✨ Claude로 콘티 자동 작성** — 컷 편집 화면의 버튼 하나로 Claude가 컷별 콘티를 써서 컷 편집기에 바로 채웁니다.
   - 판단된 유형(스토리형 V1 / 정보형 V2)의 마스터 프롬프트 + 꼼쥐 핵심 규칙 + 입력 내용으로 요청
   - 컷마다 템플릿·문구·표정·캐릭터·장면·배경·연출, 그리고 캡션·해시태그·검토 사항까지 받아옵니다
   - **API 키 불필요**: claude.ai 링크로 열었을 때 쓰는 사람의 claude.ai 사용량으로 동작합니다
   - 공용 링크나 내 컴퓨터에서 열면 이 버튼은 숨겨지고, 나머지 기능은 그대로 쓸 수 있습니다

### 1차 목표 (MVP) — AI 없이 동작
- **기획 입력 폼**
  - 콘텐츠 종류: 인스타툰 / 릴스 / 주제 추천
  - 주제, 실제 경험 메모, 실제 수치(숫자 후킹은 여기 적은 수치만 사용)
  - 유형: 자동 / A 스토리형 / B 정보형 / C 비교형 / D 리스트형 / E 후기형
  - 등장 캐릭터: 꼼쥐(기본) / 남편 / 친구
  - 목표 행동(CTA): 저장 / 공유 / 댓글 (댓글 키워드 + 보낼 자료)
- **컷 편집기**
  - 컷 추가·삭제·순서 변경 (기본 8~12컷)
  - 컷마다 템플릿 4종 선택: 표지형 / 스토리형 / 정보형 / 비교형
  - 템플릿별 입력 칸 (예: 정보형 → "첫째," 라벨, 소제목, 설명 2줄, 요약 박스)
  - 표정 선택: 기본 / 깜짝(눈물) / 고민(손가락 턱) / 뿌듯 / 하트
- **이미지 프롬프트 자동 조립**
  - 지침 11번 공통 문구 + 등장 캐릭터 추가 문구 + 템플릿 구성 + 컷 내용
  - 컷별 **복사** 버튼, 전체 콘티 한 번에 복사
- **최종 검토 자동 체크** (지침 3·6·9번)
  - 대사 2줄 초과, 한 줄 15자 초과 경고
  - 연속된 컷의 같은 문장 반복 경고
  - 입력하지 않은 숫자가 문구에 들어가면 "실제 수치 확인" 경고
  - 가격·시기·운영시간 등 변동 정보에 "검증 필요" 표시
  - 브랜드 로고 관련 단어(예: 사과 로고) 경고
- **레퍼런스 보기** — 캐릭터 턴어라운드와 템플릿 4종 이미지를 옆에서 확인
- **프로젝트 저장** — 브라우저(`localStorage`)에 자동 저장, 새로고침해도 유지

### 2차 목표
- **Claude 요청문 만들기** — 입력값 + 지침을 합쳐 claude.ai에 붙여 넣을 요청문 생성
- **릴스 스크립트 편집기** — 시간 / 화면 / 자막 / 내레이션 표, 촬영 컷 목록
- **캡션 + 해시태그** 입력 도우미 (첫 줄 후킹 → 요약 3줄 → CTA → 해시태그 5~10개)
- 툰과 릴스를 **같은 댓글 키워드·자료**로 묶는 시리즈 관리
- 내보내기/가져오기 (`.md`, `.json`)

### 3차 목표 (결정 필요)
- **AI 자동 생성** — 브라우저에서 Claude API를 직접 호출해 콘티 초안을 받아오기
  - API 키를 브라우저에 두는 방식의 보안 문제, 비용을 먼저 정한 뒤 진행합니다.

## 🛠 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 화면 | HTML + CSS (Flexbox/Grid, CSS 변수) | 빌드 없이 바로 열림 |
| 동작 | 순수 JavaScript (ES Modules) | 프레임워크 학습 부담 없음 |
| 저장 | `localStorage` | 서버 없이 브라우저에 저장 |
| 배포 | GitHub Pages (공개 저장소) | 무료, `main`에 합치면 바로 반영 |

## 🚀 실행 방법

### 공용 링크 (GitHub Pages)
👉 **https://yujinfield.github.io/my-page/instatoon/**

- `main`에 합쳐지면 1~2분 뒤 자동으로 반영됩니다. (저장소 Settings → Pages: `main` / `(root)`)
- 저장소가 **공개(public)**라서 지침·마스터 프롬프트·캐릭터 이미지는 누구나 볼 수 있습니다. API 키는 저장소에 없습니다.
- ✨ Claude 콘티 자동 작성·노션 자동 저장은 claude.ai 링크에서만 됩니다. 공용 링크에서는 요청문 복사를 쓰세요.

### 내 컴퓨터에서 열기
처음 한 번 (Mac 터미널):
```bash
cd ~/Documents
git clone https://github.com/yujinfield/my-page.git
```

쓸 때마다:
```bash
cd ~/Documents/my-page
git pull                      # 최신 변경 받아오기
python3 -m http.server 8000   # 서버 켜기 (끌 때는 Ctrl + C)
# 브라우저에서 http://localhost:8000/instatoon/ 열기
```

> `index.html`을 더블클릭해서 열면 동작하지 않습니다. (JavaScript 모듈은 서버로 열어야 함)
> 입력한 내용은 그 브라우저에만 저장됩니다.
