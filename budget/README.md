# 우리집 가계부

맞벌이 부부용 가계부입니다. **누가 얼마 썼는지**보다 **달마다 얼마가 남고, 그 돈이 자산으로 쌓이는지**를 보는 데 집중합니다.

서버·빌드 없이 순수 HTML/CSS/JavaScript 정적 파일로 만들고, GitHub Pages로 배포합니다.
데이터는 이 브라우저의 `localStorage`에만 저장됩니다. (금액 단위: 만원)

## 화면 6개

1. **월 가계부** — 예산(월 예상액)을 한 번 정해 두고, ② 실제 사용에 적은 실제액과의 차이를 봅니다.
   - 공동 항목은 예상액을 직접, 개인 항목(월급·용돈)은 두 사람 금액을 적으면 합이 예상액
   - 항목마다 두 사람이 각자 결제 수단(신한카드, 삼성카드 등) 선택. 목록은 ⚙️ 설정에서 사람마다 고치거나 "＋ 새로 추가…"로 추가
   - 위쪽 요약: 월 수입 / 지출 / 저축·투자 / 남는 돈 / 자산으로 쌓이는 돈 (예상 vs 실제)
   - `월 수입 − 지출 − 저축·투자 = 남는 돈`, `저축·투자 + 남는 돈 = 자산으로 쌓이는 돈`
2. **실제 사용** — 그 달에 실제로 받은·쓴 금액을 항목마다 적는 화면. 남은 지출 예산과 항목별 차이가 바로 보임
3. **카드 실적** — 사람마다 카드(결제 수단)별 그 달 사용액과 쓴 항목, 목표 실적(전월 실적 조건 등)까지 남은 금액
4. **큰돈 캘린더** — 결혼·신혼여행·가전·자동차 보험·성과급처럼 월 가계부에 섞으면 안 되는 돈
   - "상시"가 맨 위, 그 아래는 날짜순으로 자동 정렬. "✓ 완료"를 누르면 숨기고, "완료된 이벤트 보기"로 다시 볼 수 있음
   - "세부 ▾"로 이벤트마다 세부 항목(숙소, 비행기, 경비 등)을 적으면 예상·확정 지출이 세부 항목 합계로 계산됨
5. **연간 요약** — 12달 실적 표, 달마다 자산으로 쌓인 돈 세로 막대 그래프(가로축: 월, 점선: 예산), **"이대로 가면 N년 뒤 M억"** 코멘트
   - 현재 자산·목표 금액·연 수익률을 넣으면 예산 기준 / 최근 실적 기준(실제액을 모두 적은 달 평균)으로 계산
6. **백업·이력** — 백업 파일(.json) 내려받기·불러오기, 변경 이력(최근 300개)

월 가계부에는 그래프도 있어요: 수입이 어디로 가는지 원형 그래프(예산 / 실제)와 구분별 예산 vs 실제 막대 그래프.

## 실행

```bash
python3 -m http.server 8000   # http://localhost:8000/budget/
```
