# ✈️ 여행 블로그 메이커

여행을 다녀와서 **기억나는 것만 메모처럼 적으면**, 그 내용을 정리해
**블로그 글 초안**으로 만들어 주는 웹사이트입니다.
설치나 회원가입 없이 브라우저에서 바로 쓰고, 적은 내용은 내 브라우저에 저장됩니다.

> 이 사이트는 내가 적지 않은 경험·가격·평가를 **지어내지 않습니다.**
> 빈 곳은 `[입력 필요]`로 남겨 두고, 글은 내가 마지막에 다듬어 올립니다.

---

## ✨ 주요 기능

### 1차 목표 (MVP) — AI 없이 동작
- **여행 기본 정보 입력**
  - 여행지, 기간(시작일~종료일), 함께 간 사람, 여행 목적 / 한 줄 소감
- **일정별 메모** — 날짜(또는 장소)마다 카드를 추가해서 적기
  - 간 곳, 먹은 것, 비용, 이동 방법, 좋았던 점 / 아쉬웠던 점, 사진 메모(어떤 사진을 넣을지)
  - 카드 추가·삭제·순서 변경
- **글 스타일 선택**
  - 후기형(일기처럼 시간순) / 정보형(코스·비용·꿀팁 정리) / 감성형(짧은 에세이)
  - 말투: 해요체 / 반말 / 담백한 문어체
- **블로그 요청문 만들기**
  - 입력 내용 + 글 스타일 규칙을 합쳐 Claude 등 AI에 붙여 넣을 **요청문**을 만들고 **복사**
- **템플릿 초안 자동 조립** (AI 없이)
  - 제목 후보, 도입부, 일정별 본문, 비용 정리 표, 꿀팁 목록, 마무리를 규칙대로 이어 붙인 초안
  - 마크다운으로 보기 / 복사
- **자동 저장** — 입력 내용은 브라우저(`localStorage`)에 저장, 새로고침해도 유지

### 2차 목표
- 여행 **여러 개 관리** (목록, 삭제, 복제)
- **해시태그 추천** — 여행지·장소 이름으로 태그 후보 만들기
- 총비용 자동 합계, 1인당 비용 계산
- 플랫폼별 형식: 네이버 블로그 / 티스토리 / 인스타그램 캡션
- 내보내기/가져오기 (`.md`, `.json`)
- 다크 모드, 모바일에서 한 화면씩 입력

### 3차 목표 (결정 필요)
- **AI 자동 생성** — 브라우저에서 Claude API를 직접 호출해 완성된 글 받아오기
  - 정적 사이트라 API 키를 숨길 곳이 없습니다. 내 키를 내 브라우저에만 저장하는 방식 등, 방법을 정한 뒤 진행합니다.

## 🧭 사용 흐름

```
① 여행 기본 정보 → ② 일정별 메모 → ③ 글 스타일 선택 → ④ 결과
                                                   ├─ 요청문 복사 → AI에 붙여 넣기
                                                   └─ 템플릿 초안 복사 → 블로그에 붙여 넣고 다듬기
```

## 🛠 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 화면 | HTML + CSS (Flexbox/Grid, CSS 변수) | 빌드 없이 바로 열림 |
| 동작 | 순수 JavaScript (ES Modules) | 프레임워크 학습 부담 없음 |
| 저장 | `localStorage` | 서버 없이 브라우저에 저장 |
| 배포 | GitHub Pages | 무료, push 하면 바로 반영 |

## 📁 폴더 구조 (예정)

```
travel-blog/
├── index.html          # 진입점
├── README.md
├── CLAUDE.md           # AI 작업 가이드
├── css/
│   ├── base.css        # 색상 변수, 폰트, 리셋, 다크 모드
│   ├── layout.css      # 단계 탭 / 본문 배치, 반응형
│   └── form.css        # 입력칸, 일정 카드, 결과 화면
└── js/
    ├── store.js        # localStorage 읽기/쓰기
    ├── fields.js       # 입력 질문 목록, 빈 여행 데이터
    ├── days.js         # 일정 카드 편집 (추가·삭제·순서)
    ├── styles.js       # 글 스타일·말투 규칙 문구
    ├── prompt.js       # 입력 → AI 요청문 (순수 함수)
    ├── draft.js        # 입력 → 템플릿 초안 (순수 함수)
    └── app.js          # 진입점, 모듈 연결
```
