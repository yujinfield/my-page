# ✈️ 여행 글 메이커 (파트너스 블로그 글 자동 작성)

**이심 · 숙소 · 투어 · 패키지** 중 하나를 고르고 내 여행 경험을 적으면,
파트너스(제휴) 링크 버튼과 대가성 문구가 들어간 **블로그 후기 글**을 자동으로 만들어 주는 웹사이트입니다.
목적은 마이리얼트립·클룩·아고다·쿠팡 파트너스 등 **제휴 마케팅 수익화**입니다.

> AI나 서버 없이 브라우저에서만 동작합니다. 입력한 내용을 정해진 글 구조(템플릿)에 맞춰 조립합니다.
> 입력하지 않은 경험·수치는 지어내지 않고 `[입력 필요]`로 표시합니다.

## 실행

```bash
python3 -m http.server 8000   # http://localhost:8000/travel-blog/
```

복사 기능(클립보드)은 `localhost` 또는 `https` 주소에서만 동작합니다. 파일을 더블클릭해서 열면 안 됩니다.

## ✨ 지금 쓸 수 있는 기능

1. **글 종류 선택** — 📶 이심 / 🏨 숙소 / 🚌 투어 / 🧳 패키지
2. **입력** (입력하는 대로 오른쪽 미리보기가 바뀝니다)
   - 기본 정보: 메인 키워드, 여행지, 시기, 동행, 상품 이름, 가격, 고른 이유
   - 종류별 상세: 이심(통신망·요금제·설치 순서·속도) / 숙소(위치·객실·조식) / 투어(코스·가이드·포함 사항) / 패키지(일정·항공·선택관광)
   - 장단점과 총평: 좋았던 점, 아쉬운 점, 추천 대상, 꿀팁, 별점, 한 줄 총평
   - 파트너스 링크: 제휴 프로그램, 내 링크, 버튼 문구
3. **결과**
   - SEO 제목 후보 3개 (메인 키워드가 앞에 오도록)
   - 본문: 대가성 문구 → 들어가는 말 → 한눈에 보기 표 → 링크 버튼 → 고른 이유 → 종류별 본문 → 장단점 → 추천 대상 → 꿀팁 → 총평 → 링크 버튼 → 해시태그
   - 복사 버튼 4종: **서식 그대로 복사**(네이버·티스토리 편집기), **HTML 복사**(티스토리 HTML 모드), **텍스트 복사**, **해시태그 복사**
   - 빈칸 개수, 링크 누락 경고
- 입력 내용은 브라우저에 자동 저장됩니다. 기본 정보·장단점·링크는 종류를 바꿔도 유지되고, 종류별 상세는 따로 저장됩니다.
- 다크 모드, 모바일 폭(375px) 지원

## 💰 수익화 체크리스트

- [x] 글 맨 위에 **대가성 문구**(공정거래위원회 추천·보증 심사지침) 자동 삽입. 쿠팡 파트너스는 쿠팡이 정한 문구를 그대로 사용
- [x] 링크에 `rel="sponsored nofollow"` 적용
- [x] 링크 버튼은 본문 중간(한눈에 보기 아래)과 마지막, 두 번 들어감
- [ ] 각 제휴 프로그램 약관을 직접 확인하세요. (예: 일부 프로그램은 링크 단축이나 특정 문구를 금지합니다)
- [ ] **직접 경험한 내용만** 적으세요. 써 보지 않은 상품의 거짓 후기는 공정위 제재와 제휴 해지 사유가 됩니다.

## 📁 파일 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 마크업 뼈대, CSS/JS 불러오기 |
| `css/base.css` | CSS 변수(색상·간격·폰트), 리셋, 다크 모드 |
| `css/layout.css` | 머리말 / 종류 탭 / 입력·결과 2단 배치, 반응형 |
| `css/form.css` | 입력칸, 카드, 버튼, 결과·미리보기 |
| `js/categories.js` | 글 종류 4개와 입력 항목, 종류별 본문 구성 (데이터) |
| `js/writer.js` | 입력값 → 제목·본문·해시태그, HTML/텍스트 변환 (순수 함수) |
| `js/form.js` | 항목 목록을 보고 입력칸을 그림 |
| `js/store.js` | `localStorage` 읽기/쓰기 (이 파일에서만) |
| `js/app.js` | 진입점. 상태를 들고 각 모듈을 연결 |

새 글 종류를 추가하려면 `js/categories.js`의 `CATEGORIES`에 항목 하나만 더하면 됩니다.
