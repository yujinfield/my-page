# CLAUDE.md — 여행 글 메이커

이 파일은 Claude(AI)가 `travel-blog/` 폴더에서 작업할 때 따르는 가이드입니다.

## 프로젝트 개요

이심·숙소·투어·패키지 중 하나를 골라 입력하면 파트너스(제휴) 링크가 들어간 블로그 후기 글을 만들어 주는 웹사이트입니다.
목적은 제휴 마케팅 수익화입니다. 서버·빌드 없이 정적 파일만으로 동작합니다. 기능과 로드맵은 `README.md`를 기준으로 합니다.

- 이 앱의 코드는 모두 `travel-blog/` 폴더 안에 둡니다.
- 저장소 루트의 `index.html`, `memo/`, `instatoon/`은 **요청이 없으면 수정하지 마세요.**

## 원칙

1. **빌드 도구·프레임워크 금지** — 순수 HTML/CSS/JavaScript(ES Modules)만 사용합니다.
2. **외부 라이브러리 금지** — CDN 포함 어떠한 외부 라이브러리도 사용하지 않습니다.
3. **파일 분리 필수** — `<style>` 태그나 인라인 `<script>`를 쓰지 않습니다. (단, `writer.js`가 만드는 **블로그 글 HTML** 안의 `style` 속성은 블로그 편집기에 붙여 넣을 때 모양을 지키기 위한 것이므로 예외입니다.)
4. **기존 기능 보존** — 요청받은 범위만 변경합니다.
5. **단순하게** — 사용자는 웹 개발을 배우는 중입니다. 짧고 읽기 쉬운 코드를 우선합니다.
6. **한국어** — UI 문구, 주석, 커밋 메시지 본문은 한국어로 작성합니다. (변수·함수 이름은 영어)
7. **지어내지 않기** — 사용자가 입력하지 않은 경험·수치·평가를 글에 채워 넣지 않습니다. 빈 칸은 `[입력 필요]`로 표시합니다. 거짓 후기를 만드는 기능은 추가하지 않습니다.
8. **대가성 표시 유지** — 글 맨 위 대가성 문구와 링크의 `rel="sponsored"`는 빼지 않습니다.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `js/categories.js` | 글 종류와 입력 항목, 종류별 본문 구성 (데이터만) |
| `js/writer.js` | 입력값 → 블록 → HTML/텍스트 (순수 함수, DOM 사용 금지) |
| `js/form.js` | 입력칸 그리기 |
| `js/store.js` | `localStorage` 읽기/쓰기는 **이 파일에서만** |
| `js/app.js` | 진입점, 상태 보관, 복사·테마 |

- 새 글 종류는 `categories.js`의 `CATEGORIES`에 추가합니다. `writer.js`는 고치지 않아도 되게 유지합니다.
- 저장 형식을 바꾸면 `store.js`의 `DRAFT_VERSION`을 올리고, 기존 입력이 사라지지 않게 마이그레이션을 추가합니다.

## 보안

- 글 HTML의 모든 사용자 글자는 `escapeHtml()`을 거칩니다. 미리보기는 이 결과만 `innerHTML`에 넣습니다.
- 링크는 `safeLink()`로 `http(s)://`만 허용합니다.
- 그 밖의 사용자 텍스트는 `textContent`로 넣습니다.

## 실행 & 확인

```bash
python3 -m http.server 8000   # http://localhost:8000/travel-blog/
```

- [ ] 4가지 종류 모두 미리보기가 나오는가
- [ ] 새로고침해도 입력이 남아 있는가
- [ ] 복사 버튼 4개가 동작하는가
- [ ] 다크 모드와 375px 폭에서 레이아웃이 깨지지 않는가
- [ ] 브라우저 콘솔에 에러가 없는가
