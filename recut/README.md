# ✂️ 꼼쥐 리컷 (12컷 이미지 자르기 → 4:5 인스타툰 다시 그리기)

여러 컷이 한 장에 모여 있는 이미지(예: 4열 × 3행 = 12컷)를 올리면
**컷마다 잘라서** 보여 주고, 각 컷을 **4:5(1080×1350) 인스타툰 한 장**으로 다시 그려 주는 웹사이트입니다.

> 기획(콘티 쓰기)은 [꼼쥐툰 메이커](../instatoon/)가 하고,
> 이 사이트는 **이미 있는 컷 묶음 이미지를 인스타 한 장 한 장으로 옮기는 일**만 합니다.

---

## ✨ 주요 기능

### 1차 목표 (MVP) — 자르기 (AI 없이 동작)
- **이미지 올리기** — 파일 선택 또는 끌어다 놓기 (PNG/JPG)
- **격자 설정** — 행·열 수 (기본 3행 × 4열 = 12컷), 바깥 여백, 컷 사이 간격
  - 원본 위에 자르는 선을 겹쳐 보여 주고, 숫자를 바꾸면 바로 갱신
- **컷 나누기** — 왼쪽 → 오른쪽, 위 → 아래 순서로 01~12번
  - 컷마다 미리보기, 위치 미세 조정(위·아래·좌·우 몇 px)
- **4:5로 맞추기** — 잘린 컷(예: 234×375)을 1080×1350 캔버스에 놓는 방법 선택
  - 여백 채우기(아이보리 배경) / 가운데 잘라 채우기
- **내려받기** — 컷별 PNG, 전체 한 번에(차례로) 내려받기 (`01.png` ~ `12.png`)

### 2차 목표 — 다시 그리기 (GPT 이미지)
- 컷마다 **🎨 이 컷 다시 그리기** / **전체 다시 그리기** (시작 전 비용 확인, 한 장씩 차례로, 멈추기)
- 참고 이미지: **잘라 낸 원본 컷** + 꼼쥐 턴어라운드(`../instatoon/references/꼼쥐_턴어라운드.png`)
- 프롬프트 = 공통 스타일(지침 11번) + 이 컷의 문구·장면 + 고정 조건(4:5, 아이보리 배경, 상단 중앙 '@꼼쥐')
- 컷마다 **문구·수정 메모** 칸 — 원본 그림 속 문구를 옮겨 적고, 바꾸고 싶은 점을 적음
- 다시 그린 그림 모두 남기기(◀ 이전 / 다음 ▶), 수정 요청으로 고쳐 그리기, 내려받기

### 3차 목표
- 자르는 선 자동 찾기 (컷 사이 흰 간격을 읽어서 격자 추천)
- 컷 문구 자동 읽기 (그림 속 한글을 AI로 읽어 문구 칸 채우기)
- 원본·다시 그린 그림 나란히 비교 보기
- 작업 저장·불러오기 (`.json` 내보내기)

## 🧭 작업 흐름

```
원본 12컷 이미지 ─▶ 격자 맞추기 ─▶ 12장으로 자르기 ─▶ 4:5로 맞추기 ─▶ 내려받기
                                         │
                                         └▶ 컷마다 문구·수정 메모 ─▶ 🎨 다시 그리기 ─▶ 내려받기
```

예시 원본과 컷별 문구는 [`samples/wedding-nail/`](./samples/wedding-nail/)에 있습니다.

| 파일 | 내용 |
| --- | --- |
| `samples/wedding-nail/original.jpg` | "웨딩 촬영 네일 10만원 주고 해야 하나요?" 12컷 원본 (938×1125, 4열 × 3행) |
| `samples/wedding-nail/cuts.md` | 12컷 문구·그림 설명 대본, 컷마다 수정 메모 칸 |

## 🛠 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 화면 | HTML + CSS (Grid, CSS 변수) | 빌드 없이 바로 열림 |
| 동작 | 순수 JavaScript (ES Modules) | 프레임워크 학습 부담 없음 |
| 자르기 | `<canvas>` (`drawImage`, `toBlob`) | 브라우저 안에서 처리, 서버로 이미지 안 보냄 |
| 다시 그리기 | OpenAI 이미지 API (브라우저에서 직접) | 서버 없음, 키는 사용자가 입력 |
| 저장 | `localStorage` (설정만) | 이미지는 메모리에만, 내려받기로 저장 |
| 배포 | GitHub Pages (공개 저장소) | `main`에 합치면 바로 반영 |
