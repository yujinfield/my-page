# ✂️ 꼼쥐 리컷 (12컷 이미지 자르기 → 4:5 인스타툰 다시 그리기)

여러 컷이 한 장에 모여 있는 이미지(예: 4열 × 3행 = 12컷)를 올리면
**컷마다 잘라서** 보여 주고, 각 컷을 **4:5(1080×1350) 인스타툰 한 장**으로 다시 그려 주는 웹사이트입니다.

> **어떤 컷 묶음 이미지든** 쓸 수 있습니다. 행·열 수는 자유이고, 그림체도 원본을 그대로 따라갑니다.
> @꼼쥐 인스타툰일 때만 "꼼쥐툰 스타일"을 골라 지침 문구와 턴어라운드를 함께 쓸 수 있습니다.
> 기획(콘티 쓰기)은 [꼼쥐툰 메이커](../instatoon/)가 하고, 이 사이트는 **이미 있는 컷 묶음 이미지를 인스타 한 장 한 장으로 옮기는 일**만 합니다.

## ✨ 주요 기능

### ✅ 자르기 (AI 없이 동작)
- **이미지 올리기** — 파일 선택 또는 끌어다 놓기 (PNG/JPG/WebP), 또는 **예시 불러오기**
- **격자 설정** — 세로 칸 수(행)·가로 칸 수(열) (기본 세로 3 × 가로 4 = 12컷, 1~10까지), 바깥 여백, 컷 사이 간격
  - 원본 위에 자르는 선과 컷 번호를 겹쳐 보여 주고, 숫자를 바꾸면 바로 갱신
  - **🔍 자동 맞추기** — 컷 사이 밝은 간격을 찾아 경계선을 맞춤 (AI 그림처럼 컷 폭이 조금씩 달라도 됨)
- **컷 나누기** — 왼쪽 → 오른쪽, 위 → 아래 순서로 01, 02 …
  - 컷마다 4:5 미리보기, 위치 미세 조정(위·아래·왼쪽·오른쪽 px)
- **4:5로 맞추기** — 잘린 컷을 1080×1350에 놓는 방법 선택
  - 컷 전체 보이기(남는 곳은 아이보리) / 꽉 채우기(넘치는 곳 잘라 냄)
- **저장** — 컷별 PNG, 전체 한 번에 저장 (`01.png`, `02.png` …)
  - 휴대폰: 공유 창이 열려요. 아이폰은 "이미지 저장"을 누르면 사진 앱에 들어가요
  - 컴퓨터: 내려받기 폴더에 저장돼요
  - 카카오톡·인스타그램 안의 브라우저에서는 저장이 안 될 수 있어요. Safari·Chrome으로 여세요
- **🔍 크게 보기** — 컷 그림(원본·다시 그린 그림)을 누르면 큰 창으로 열림
  - ◀ 이전 컷 / 다음 컷 ▶ (키보드 ← →), 원본 ↔ 다시 그린 그림 전환, **⬇️ 저장**, Esc·바깥 누르면 닫힘
  - 아이폰은 큰 그림을 길게 눌러 '사진에 저장'도 됨
- 격자·컷 글은 브라우저에 저장되어 새로고침해도 남아 있습니다 (이미지는 저장하지 않음)

### ✅ 다시 그리기 (GPT 이미지)
- **③ GPT 그림 설정**에서 OpenAI API 키·모델·크기(기본 1024×1280, 4:5)·품질을 정합니다
  - **🔒 잠가서 저장**: 키를 잠금 비밀번호로 암호화(AES-GCM)해 이 기기에만 저장. 새로고침·30분 미사용이면 다시 잠김
  - **이번만 쓰기**: 저장하지 않고 이 창에서만 씀
- **그림 스타일**
  - 원본 그림체 그대로 (기본, 어떤 그림이든) + 원하면 워터마크 글자 (예: `@내계정`)
  - 꼼쥐툰 스타일: 지침 11번 문구 + `@꼼쥐`
- **🖼️ 캐릭터 참고 이미지 올리기** — 캐릭터 시트(턴어라운드)를 올리면 다시 그릴 때 두 번째 참고 이미지로 보내 외형을 맞춰요
  - 긴 쪽 1024px로 줄여 이 브라우저에 저장 (다음에 열어도 남음), 지우기 가능
  - 안 올리면 꼼쥐툰 스타일일 때만 기본 꼼쥐 턴어라운드를 보내요
- 컷마다 **컷 내용**(그림 속 문구·그림 설명)과 **수정 메모** 칸
- 컷마다 **다시 그릴 배치(여백)**: 표지형 / 정보형 / 스토리형 / 비교형 / 지정 안 함
  - 자동이면 컷 내용의 `컷 유형:` 줄을 보고 고르고, 고른 배치를 "자동 → 스토리형"처럼 바로 보여 줍니다 (CTA형은 스토리형, 못 정하면 "못 정함")
  - @꼼쥐 레퍼런스 그림의 여백을 재서 넣은 값이라, 다시 그린 그림이 레퍼런스처럼 넉넉한 여백으로 나옵니다
  - 비워 두면 "원본 컷의 글자를 그대로 옮기라"고 요청합니다
- 컷마다 **🎨 다시 그리기** / **🎨 전체 다시 그리기**(시작 전 비용 확인, 한 장씩 차례로, ⏹ 멈추기)
- 다시 그린 그림은 모두 남아서 **◀ 이전 / 다음 ▶**으로 오가고, **✏️ 이 그림 고치기**로 수정 메모대로 고쳐 그립니다
- 다시 그린 그림은 화면에만 있으니(새로고침하면 사라짐) **⬇️ 다시 그린 그림** 또는 **⬇️ 다시 그린 그림 전체 내려받기**로 저장하세요 (`01_redraw.png`)
- 실패하면 컷 아래에 무엇이 문제인지와 해결 방법을 한국어로 보여 줍니다 (키 오류, 크레딧 부족, 모델 없음 등)

## 🛠 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 화면 | HTML + CSS (Grid, CSS 변수) | 빌드 없이 바로 열림 |
| 동작 | 순수 JavaScript (ES Modules) | 프레임워크 학습 부담 없음 |
| 자르기 | `<canvas>` (`drawImage`, `toBlob`) | 브라우저 안에서 처리, 서버로 이미지 안 보냄 |
| 다시 그리기 | OpenAI 이미지 API (브라우저에서 직접) | 서버 없음, 키는 사용자가 입력 |
| 저장 | `localStorage` (설정만) | 이미지는 메모리에만, 내려받기로 저장 |
| 배포 | GitHub Pages (공개 저장소) | `main`에 합치면 바로 반영 |

## 🚀 실행 방법

```bash
cd ~/Documents/my-page
git pull
python3 -m http.server 8000   # 끌 때는 Ctrl + C
# 브라우저에서 http://localhost:8000/recut/ 열기
```

공용 링크: **https://yujinfield.github.io/my-page/recut/** (`main`에 합쳐진 뒤)

> 다시 그리기는 공용 링크나 내 컴퓨터(localhost)에서 동작합니다. claude.ai 링크는 외부 인터넷이 막혀 OpenAI에 연결할 수 없어요.

> `index.html`을 더블클릭해서 열면 동작하지 않습니다. (JavaScript 모듈은 서버로 열어야 함)
> 올린 이미지는 서버로 보내지 않고 브라우저 안에서만 자릅니다. 다시 그리기를 누를 때만 그 컷이 OpenAI로 전송됩니다.
