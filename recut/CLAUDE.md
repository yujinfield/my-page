# CLAUDE.md — 꼼쥐 리컷

이 파일은 Claude(AI)가 `recut/` 폴더에서 작업할 때 따르는 가이드입니다.

## 프로젝트 개요

여러 컷이 한 장에 모인 이미지(기본 4열 × 3행 = 12컷)를 컷마다 잘라
**4:5(1080×1350) 인스타툰 한 장씩**으로 만들고, 필요하면 컷마다 다시 그리는 웹사이트입니다.
서버·빌드 없이 정적 파일만으로 동작합니다. 기능과 로드맵은 `README.md`를 기준으로 합니다.

**범용 도구입니다.** 어떤 컷 묶음 이미지든(행·열 수, 그림체, 언어 상관없이) 쓸 수 있어야 합니다.
웨딩 네일 12컷은 예시일 뿐이고, @꼼쥐 전용 규칙은 "꼼쥐툰 스타일"을 골랐을 때만 적용합니다.
특정 이미지·계정에만 맞는 값(컷 수, 문구, 워터마크 등)을 코드에 고정하지 않습니다.

저장소는 **공개**이고 GitHub Pages(`https://yujinfield.github.io/my-page/recut/`)로 배포합니다.
`samples/`에 넣는 이미지·대본도 공개된다는 점을 염두에 둡니다.

- 이 앱의 코드는 모두 `recut/` 폴더 안에 둡니다.
- 저장소 루트의 `index.html`(버킷리스트), `memo/`(메모 앱), `instatoon/`(꼼쥐툰 메이커)는 **요청이 없으면 수정하지 마세요.**
- `instatoon/`의 JS 파일을 `import` 하지 않습니다 (두 앱이 서로 깨뜨리지 않게). 비슷한 코드가 필요하면 `recut/js/`에 짧게 다시 씁니다.
- 예외로 **읽기만** 하는 공용 자료는 상대 경로로 씁니다.
  - 꼼쥐 외형 기준: `../instatoon/references/꼼쥐_턴어라운드.png` (꼼쥐툰 스타일 + 턴어라운드 켬일 때만 보냄)
  - 꼼쥐툰 스타일 프롬프트 원본: `../instatoon/guidelines.md` 11번. `redraw-prompt.js`의 `KKOMJWI_STYLE`에 옮겨 두었으니 지침이 바뀌면 함께 고칩니다 (지침을 고칠 일이 생기면 사용자에게 먼저 확인)

## 원칙

1. **빌드 도구·프레임워크 금지** — React, Vue, npm 번들러, TypeScript를 도입하지 않습니다. 순수 HTML/CSS/JavaScript만 사용합니다.
2. **외부 라이브러리 금지** — CDN 포함 어떠한 외부 라이브러리도 사용하지 않습니다. 자르기는 `<canvas>`로 직접 구현합니다.
3. **파일 분리 필수** — HTML, CSS, JavaScript는 반드시 별도 파일로 작성합니다. `<style>` 태그나 `<script>` 인라인 코드는 작성하지 않습니다.
4. **기존 기능 보존** — 요청받지 않은 기존 기능은 임의로 삭제하거나 변경하지 않습니다. 수정 시 요청받은 범위만 변경합니다.
5. **단순하게** — 사용자는 웹 개발을 배우는 중입니다. 짧고 읽기 쉬운 코드, 명확한 이름을 우선합니다.
6. **한국어** — UI 문구, 주석, 커밋 메시지 본문은 한국어로 작성합니다. (변수·함수 이름은 영어)
7. **원본 내용 지키기** — 다시 그릴 때 원본 컷의 문구·장면·순서를 바꾸지 않습니다. 사용자가 "수정 메모"에 적은 것만 바꿉니다. 원본에 없는 문구·수치를 지어내지 않습니다.
8. **범용성** — 새 기능은 꼼쥐가 아닌 다른 그림·다른 컷 수에서도 동작해야 합니다. 꼼쥐 전용 동작은 `style === 'kkomjwi'`일 때만 켭니다.

## 자르기 규칙

- **컷 번호**: 왼쪽 → 오른쪽, 위 → 아래. 4열 × 3행이면 1행이 01~04, 2행이 05~08, 3행이 09~12입니다.
- 기본 격자는 **3행 × 4열**입니다. 화면에는 "세로 칸 수 (행)", "가로 칸 수 (열)"로 보여 줍니다 (사용자가 헷갈리지 않게 행·열만 쓰지 않음). 1~10, 바깥 여백, 컷 사이 간격(px)은 사용자가 바꿀 수 있습니다.
- **자동 맞추기**: 열·행마다 평균 밝기를 재고, 균등 분할 위치 근처(칸 크기의 ±15%)에서 가장 밝은 줄을 경계선으로 고릅니다 (`grid.xLines`/`yLines`). 행·열 수를 바꾸면 경계선을 버리고 균등 분할로 돌아갑니다. 예시를 불러오면 자동으로 맞춥니다.
- 좌표 계산은 원본 픽셀 기준으로 하고, 화면 미리보기 크기와 섞지 않습니다. 소수점은 `Math.round`로 정리합니다.
- 컷마다 위·아래·좌·우 미세 조정 값(px)을 따로 둘 수 있습니다. 조정해도 원본 이미지 밖으로 나가지 않게 자릅니다.
- **4:5 맞추기**: 출력은 항상 1080×1350입니다. 원본 컷은 보통 4:5가 아니므로(예시: 약 234×375) 방식을 고릅니다.
  - `fit`(기본): 컷 전체가 보이게 줄이고, 남는 곳은 아이보리 배경색으로 채움
  - `fill`: 4:5가 꽉 차게 키우고 넘치는 곳은 가운데 기준으로 잘라 냄
- 원본이 작아서 크게 늘리면 흐려집니다. 자른 컷은 **다시 그리기의 참고 이미지**로 쓰는 것이 주 목적임을 화면에 알려 줍니다.
- 올린 이미지는 서버로 보내지 않습니다. 브라우저 안에서만 자르고, 결과는 메모리에만 두며 내려받기로 저장합니다.
- 내려받기 파일 이름: `01.png` ~ `12.png` (두 자리), 다시 그린 그림은 `01_redraw.png`. 파일 이름은 `downloads.js` 한 곳에서만 정합니다.
- 저장은 모두 `downloads.js`의 `saveFiles([{ blob, fileName }])` 하나로 합니다. 터치 화면 + 파일 공유가 되면 `navigator.share`(아이폰 "이미지 저장" → 사진 앱), 아니면 `<a download>`. 공유가 막히면(사용자 동작 뒤 시간이 지나 허락이 풀린 경우 등) 내려받기로 넘어갑니다. blob 주소는 1분 뒤에 지웁니다 (너무 빨리 지우면 Safari에서 실패).
- 크게 보기 창은 원본도 `<img>`(blob 주소)로 보여 줍니다. 아이폰에서 길게 눌러 '사진에 저장'하려면 캔버스가 아니라 `<img>`여야 합니다. 새 주소를 만들면 이전 주소는 `URL.revokeObjectURL`로 지웁니다.

## 다시 그리기 (GPT 이미지)

목표: 원본 컷 각각을 **같은 내용 그대로 4:5 인스타툰 한 장**으로 새로 그리기.

- 모두 OpenAI `/v1/images/edits`로 보냅니다 (참고 이미지가 항상 있음).
  - 다시 그리기: ① 잘라 낸 원본 컷 ② 캐릭터 참고 이미지 ("함께 보내기" 켬일 때. 올린 이미지가 우선, 없으면 꼼쥐툰 스타일일 때만 기본 꼼쥐 턴어라운드)
  - 고치기: ① 지금 보고 있는 다시 그린 그림
- 크기: 기본 `1024x1280`(4:5). 모델이 거절하면 오류 문구를 그대로 보여 주고 다른 크기를 고르게 합니다.
- **스타일** (`settings.style`):
  - `original`(기본): 원본 그림체·색·캐릭터를 그대로 따름. 워터마크는 사용자가 적은 글자(비우면 없음)
  - `kkomjwi`: 지침 11번 문구 + 꼼쥐 입 없음 규칙, 워터마크 `@꼼쥐`
- 프롬프트(`buildRedrawPrompt`) 순서:
  1. 스타일 문구
  2. 이 컷의 역할 — "N컷 중 M번째, 원본 컷의 내용·문구·구도를 유지하고 세로 4:5로 다시 배치"
  3. 배치(여백) — 아래 "템플릿별 여백" (컷의 `layout`, 자동이면 `컷 유형:` 줄로 고름)
  4. 컷 내용 — 사용자가 적은 그대로 (`그림:`·`컷 유형:` 줄은 그림 설명, 나머지 줄은 그대로 그릴 글자). 비면 "원본의 글자를 그대로"
  5. 수정 메모 — 적은 경우에만
  6. 캐릭터 시트 규칙(`CHARACTER_RULE`) — 캐릭터 참고 이미지를 보낼 때만
  7. 고정 조건 — 한 장짜리 4:5, 원본의 **컷 번호 배지(①②…)는 빼고** 그림, 브랜드 로고 없음, 워터마크
- 비용이 드니 버튼을 누를 때만, 전체 다시 그리기는 시작 전에 확인하고 한 장씩 차례로 만듭니다. 한 번에 한 장만 그리고, 자동 재시도하지 않습니다. 전체 그리기 중 실패하면 그 컷에서 멈춥니다.
- 다시 그린 그림은 메모리(`state.redraws`)에만 두고 내려받기로 저장합니다.
- API 키 방식은 아래 "보안"을 따릅니다. 오류는 `errors.js`로 한국어 안내를 만들어 그 컷 아래에 보여 줍니다.

## 템플릿별 여백

다시 그린 그림의 여백·배치는 @꼼쥐 레퍼런스(`../instatoon/references/*_레퍼런스.png`, 1122×1402)에서
잉크(선·글자)가 닿는 범위를 재서 1080×1350 기준으로 줄인 값을 `redraw-prompt.js`의 `LAYOUTS`에 둡니다.
꼼쥐가 아닌 그림에도 같은 여백을 씁니다. 값을 바꾸려면 `LAYOUTS`만 고칩니다.

| 배치 | 워터마크 | 위쪽 | 가운데 | 아래쪽 | 좌우 여백 | 아래 여백 |
| --- | --- | --- | --- | --- | --- | --- |
| 표지형 `cover` | 7~10% | 큰 제목 2~3줄 20~55% | (빈 공간 55~59%) | 캐릭터·한마디 59~94% | 약 90px | 80px 이상 |
| 정보형 `info` | 4~7% | (빈 공간 7~20%) 큰 글씨 2줄 20~38% (말풍선·상자 없이, 폭 55~60%) | (빈 공간 38~45%) | 캐릭터 + 대사 말풍선 45~95% | 약 50px (글씨는 약 220px) | 45~80px |
| 스토리형 `story` | 4~7% | 구름 말풍선(상황) 10~47% | 캐릭터 + 대사 말풍선 50~94% | — | 약 50px | 40~70px |
| 비교형 `compare` | 4~6.5% | 질문 제목 10~17%, 부제 20~23% | 좌우 카드 25~80% (각 46%, 사이 20px) | 결론 띠 81~97% | 약 45px | 30px 이상 |

- 정보형은 사용자가 따로 준 레퍼런스 2장(위쪽에 말풍선 없는 큰 글씨 2줄 + 아래쪽에 캐릭터 1~2명과 대사 말풍선)으로 바꿨습니다. `instatoon/references/정보형_레퍼런스.png`(라벨 + 제목 + 그림 + 요약 상자)와 다릅니다.
- CTA형은 스토리형 배치를 씁니다. `none`이면 배치 문구를 넣지 않습니다.
- 퍼센트는 그림 높이 기준입니다.

## 데이터 모델

이미지는 저장하지 않고, 설정과 컷별 글만 저장합니다.

```js
// localStorage 키: "recut-draft"
{
  version: 1,
  grid: { rows: 3, cols: 4, margin: 0, gap: 0 },  // px, 원본 기준
  fitMode: "fit",                                   // "fit" | "fill"
  cuts: [
    {
      nudge: { top: 0, right: 0, bottom: 0, left: 0 }, // 미세 조정 px
      text: "",   // 원본 컷 속 문구 (직접 옮겨 적기)
      memo: "",   // 다시 그릴 때 바꿀 점
      layout: "auto" // 다시 그릴 배치: "auto" | "cover" | "info" | "story" | "compare" | "none" (LAYOUTS)
    }
  ]
}
// grid에는 자동 맞추기로 찾은 경계선 xLines(cols+1개) / yLines(rows+1개)도 들어감 (없으면 null = 균등 분할)

// 그림 설정: "recut-image-settings"
{ model: "gpt-image-2", customModel: "", size: "1024x1280", quality: "auto",
  style: "original",   // "original" | "kkomjwi"
  watermark: "",        // original 스타일일 때만 씀
  useCharacterImage: true } // 캐릭터 참고 이미지 함께 보내기 (예전 이름 useTurnaround도 읽음)
// 테마: "recut-theme" ("light" | "dark")
// API 키: "recut-image-key-locked" (암호화된 값만)
// 캐릭터 참고 이미지: "recut-character-image" (긴 쪽 1024px JPEG data URL, 저장 공간이 모자라면 저장하지 않고 이 창에서만 씀)
```

- 데이터 형식을 바꾸면 `version`을 올리고 `store.js`에 마이그레이션을 추가해 **기존 작업이 사라지지 않게** 합니다.
- localStorage 키는 모두 `recut-`로 시작해 `instatoon`(`kkomjwi-`)과 섞이지 않게 합니다.

## 디자인 가이드 (사이트 화면)

- 꼼쥐툰 메이커와 같은 느낌: 아이보리 크림 배경, 파스텔 핑크·노랑·연두·하늘 포인트, 형광펜 강조.
- 테두리보다 배경색 차이로 영역을 나눕니다. 색상·간격은 `base.css`의 CSS 변수로만 지정하고, 하드코딩하지 않습니다.
- 다크 모드: `@media (prefers-color-scheme: dark)` + `[data-theme="dark"]`로 수동 전환 지원.
- 본문 폰트 크기는 16px 이상 (아이폰 Safari 입력 시 자동 확대 방지).
- 컷 카드는 넓은 화면에서 여러 열(카드 최소 폭 320px), 모바일(약 768px 이하)에서 1열. 카드 안에 원본·다시 그린 그림을 4:5 상자 두 개로 나란히 보여 줍니다.
- 버튼에는 `aria-label`, 키보드로도 모든 기능을 쓸 수 있게 합니다.

## 보안

- 사용자가 입력한 문구를 화면에 넣을 때는 항상 `textContent`를 사용합니다. `innerHTML`에 사용자 텍스트를 넣지 않습니다.
- **API 키는 절대 코드·저장소에 넣지 않고, 채팅으로 받지 않습니다.** 평문으로 저장하지 않고, 사용자가 정한 비밀번호로 암호화(Web Crypto, PBKDF2 → AES-GCM)한 값만 저장합니다. 방식은 `instatoon/CLAUDE.md`의 "그림 생성" 절과 같게 합니다.
- `index.html`에 CSP를 둡니다: `script-src 'self'`, `connect-src 'self' https://api.openai.com`, `img-src 'self' blob: data:`.
- 원본 이미지는 다시 그리기를 누른 컷만 OpenAI로 보냅니다. 그 외에는 브라우저 밖으로 내보내지 않습니다.

## 실행 & 확인

```bash
python3 -m http.server 8000   # 저장소 루트에서 → http://localhost:8000/recut/
```

자동 테스트는 아직 없습니다. 변경 후에는 다음을 직접 확인합니다.

- [ ] 예시 불러오기 → 3행 × 4열 선이 컷 경계에 맞게 겹쳐 보이고, 컷 내용 칸이 채워지는가
- [ ] 예시가 아닌 다른 이미지(다른 행·열 수)도 자르기·자동 맞추기가 되는가
- [ ] 12컷이 01~12 순서(왼→오, 위→아래)로 나뉘는가
- [ ] 내려받은 PNG가 1080×1350인가 (`fit` / `fill` 둘 다)
- [ ] 휴대폰(또는 터치 흉내)에서 ⬇️ 저장 → 공유 창이 열리는가, 컴퓨터에서는 내려받기 폴더에 저장되는가
- [ ] 행·열·간격을 바꾸면 미리보기가 바로 바뀌고, 새로고침해도 설정이 남는가
- [ ] 다시 그리기: 키 없이 누르면 안내, 잘못된 키면 한국어 오류, 꼼쥐툰 스타일에서만 참고 이미지가 2장인가 (OpenAI 응답은 가짜로 바꿔 시험해도 됨)
- [ ] 다크 모드와 모바일 폭(375px)에서 레이아웃이 깨지지 않는가
- [ ] 브라우저 콘솔에 에러가 없는가
